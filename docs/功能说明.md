# FileLens 功能说明

一个 Android 手机上的文件管理与空间清理应用。

---

## 一、这个应用解决什么问题

手机用久了会遇到四件事，FileLens 就是为它们做的：

1. **不知道空间去哪了** —— 系统只说「已用 184GB」，但不说是什么占的
2. **找文件只能靠翻** —— 记得文件叫什么，但不知道在哪个目录
3. **重复文件占着地方** —— 同一张图存了好几份，删哪份都不放心
4. **删东西怕删错** —— 删完就没了，没有后悔的机会

---

## 二、功能一览

| 模块 | 能做什么 |
|---|---|
| 空间 | 看清什么最占地方，逐层往下看 |
| 搜索 | 按名称、后缀、位置、大小、时间精确找 |
| 清理 | 找出重复文件、应用占用、可清理项 |
| 删除 | 先放进回收站，可撤销、可恢复 |
| 文件操作 | 重命名、移动、新建文件夹 |
| 传输 | 同一个 Wi-Fi 下，用电脑浏览器管手机文件 |
| 预览 | 图片直接看，能看就能删 |

## 三、逐项说明

### 3.1 空间：一眼看出谁占了地方

打开应用就是空间总览，先给三个数字：**已用 / 可用 / 已扫描**。

下面是一张铺满屏幕的**矩形图**：每个方块代表一个文件夹，方块越大，占用越多。不用点开任何目录，就能看出「原来是照片占了 5GB」。

点任意方块可以**进入下一层**，看这个文件夹里又是谁最占地方。顶部的路径条显示当前在哪，点任意一级可以直接跳回去。

还有一个**测速**功能：跑一次顺序读写和随机读写，给出手机存储的实际速度。

### 3.2 搜索：五种方式找同一个文件

| 你输入 | 它会怎么找 |
|---|---|
| `报告` | 名字里含「报告」的 |
| `.pdf` | 所有 PDF 文件 |
| `DCIM/` | 只在这个目录里找 |
| 点「>10MB」 | 只出 10MB 以上的 |
| 点「7 天内」 | 只出这周动过的 |

几种条件可以叠加。找到之后每一行都标明**大小和所在目录**，长按可以直接重命名、移动或删除，不用先跳过去。

按大小、按时间、按名称都能排序，随时切换。

### 3.3 清理：三类可以腾出空间的东西

- **重复文件**：内容完全相同的多份，列成一组一组，告诉你浪费了多少空间
- **应用占用**：每个应用占多少，可以按占用大小排，也可以按缓存大小排
- **垃圾建议**：可直接清理的项目，带体积，可以一键全选

选中之后批量删除，删完 5 秒内还能反悔。

如果手机没装 Shizuku，需要它的部分会整块隐藏，不会出现「点了没反应」的按钮。

### 3.4 删除：先收起来，不直接销毁

这是 FileLens 和普通文件管理器最大的区别。

**删除不是销毁，而是移进应用内的回收站**，并且保留原来的目录结构——从 `Download/照片/` 删的文件，回收站里还在 `Download/照片/` 下面。

删除后屏幕底部会出现「已移入回收站 · 撤销」，**5 秒内点一下就能反悔**。

回收站里的东西可以：
- **逐条恢复**，回到它原来在的地方
- **彻底删除**，真正释放空间
- 超过 **30 天**的条目自动清理，不用手动维护

**一个细节**：如果恢复时那个文件夹已经被你删掉或改名了，它会自动把文件夹建回来，把文件放回原位——不会让你「恢复」到一个不存在的地方。

对于相册里的照片，删除会走系统的删除确认，和其他应用看到的状态保持一致。

### 3.5 文件操作

- **重命名**：重名会被拒绝，不会覆盖已有文件；带路径符号的名字也会被拒绝
- **移动**：可以移动到任意目录；如果把一个文件夹拖进它自己的子文件夹，会被拒绝并提示（否则文件夹会「消失在无底洞」）
- **新建文件夹**：在当前所在目录新建

操作完列表立刻更新，不需要手动刷新，也不需要重新扫描整盘。

### 3.6 局域网传输：不用数据线

手机开一个服务，**同一个 Wi-Fi 下的电脑用浏览器就能访问**，不需要装任何客户端，不经过互联网，也不上传任何服务器。

用法：

1. 在「传输」页点开启
2. 页面会给出一个局域网地址和一个二维码，还有一组六位数字
3. 电脑浏览器输入地址（或手机扫码看地址），输入那六位数字
4. 之后就能在浏览器里浏览手机文件、下载、上传

几个细节：
- 服务**默认关闭**，要用才开
- 六位数字不会在网络上明文传输，验证之后才开始传文件
- 在手机自己身上浏览时，「下载」按钮会自动隐藏，避免自己下自己的文件
- **接收目录可以自己指定**；指定前会先试一下这个目录能不能写，不能写就不让你选

### 3.7 预览

图片可以直接打开看，大图也能正常显示，不会卡住。

打不开的文件不会黑屏，而是明确告诉你「无法解码」并给出完整路径，方便判断是什么问题。

预览页里就能删除，删完同样进回收站。

## 四、界面适配

- **手机**：底部胶囊形导航栏，高度会随屏幕宽度自动调整，不会在小屏上显得过胖
- **平板 / 大屏**：自动换成左侧图标栏 + 右侧信息栏，内容不会被拉得过宽
- 支持浅色与深色

---

## 五、需要哪些权限

| 权限 | 用来做什么 | 是否必需 |
|---|---|---|
| 所有文件访问 | 扫描全盘、统计占用、管理文件 | **必需** |
| 使用情况访问 | 统计各应用占用 | 可选 |
| 通知 | 显示传输服务是否在运行 | 可选 |
| 相机 | 扫二维码连电脑 | 可选 |

除局域网传输外，应用**不会联网**；崩溃日志只存在手机本地，不会上传。

---

## 六、第一次使用建议这样走一遍

1. 安装后打开，按提示授予「所有文件访问」
2. 等首屏加载完，看空间总览的三个数字
3. 点最大的那个方块，往下钻两级，感受一下「原来空间在这里」
4. 去搜索页输入 `.jpg`，看看照片都分布在哪
5. 去清理页看重复文件，如果有，检查一遍再决定删不删
6. 随便删一个文件试试——注意底部会出现「撤销」，点一下，看它回来
7. 想让电脑连手机的话，去传输页开启服务，用电脑浏览器访问
