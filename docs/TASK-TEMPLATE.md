# 任务书模板

> 以后给我派活，照这个填。填不下去的项，说明需求还没想清。

---

## 1. 要做什么

一句话说清目标。**不要写实现方案**，那是我的活。

```
例：让大文件排行显示 50 行，不是只显示 1 行。
```

## 2. 不改什么（同样重要）

明确划出范围，防止我"既然改到这里就把别的也改了"。

```
例：只动 RankPage.kt，不许动 TreePage、不许改底栏、不许加新页面。
```

## 3. 验收标准（必须可判定）

每条都要能答"是 / 不是"，不要写"体验更好"这种。

```
例：
- 滚动能看到 50 行
- 每行高度一致
- 点某行能进所在文件夹
```

## 4. 涉及位置

能给到 `文件:行号` 就给，能省我一半时间且少犯错。

```
例：RankPage.kt:83-87（showTop 的循环）
```

## 5. 版本与交付

```
版本：1.3.3 / versionCode 15
交付：构建后推 /sdcard/Download/FileLens-1.3.3.apk
```

## 6. 优先级

```
P0 = 功能不可用
P1 = 能用但难用
P2 = 打磨
```

## 反面例子（这些我都踩过）

| 坏的任务书 | 为什么坏 |
|---|---|
| 「把界面做好看点」 | 无法判定，我会自己发挥 |
| 「顺手把 xx 也修一下」 | 范围失控 |
| 「做一个更好的玻璃效果」 | 没有验收标准，我会做出你不想要的东西 |
| 「参考 iOS 那种」 | 参照物太模糊，我只猜到一部分 |
| 一次列 8 个不相关的任务 | 上下文变长，我记混 |

## 好例子

```markdown
## 要做什么
传输页不再自动启动服务，改为用户手动点「开启」。

## 不改什么
- 不动网页资源（assets/www）
- 不动端口配置
- 不删原有的「其他设备」入口，只改它的位置

## 验收
1. 冷启动后进传输页，服务是关闭的
2. 右上角状态点为橙色 + 文字「关闭」
3. 点它 → 变绿 + 「开启」，弹出地址
4. 停止后再进页面，不会自己启动

## 涉及位置
TransferPage.kt:120-140（状态栏）、TransferService.kt:88（自动启动）

## 版本
1.2.1 / versionCode 9
```
